What had to exist first

Guardrails

Production repositories need more than a good model. These make delegation real.

  • 01 // Human go-ahead

    Nothing merges on its own

    No direct pushes, and at most 2 open PRs per repo. In production code, an engineer reviews and merges. In internal tools, like the company site, the team that owns it gives the go-ahead in chat and the agent merges.

  • 02 // Cost & safety

    Scripts before LLMs

    Anything that can be solved with Bash, Python, or Git never calls an LLM. This prevents hallucinations, runs quiet security checks, and keeps token spend strictly under $140/mo per profile.

  • 03 // Isolation

    Each agent in its own lane

    Each profile runs in an isolated sandbox with its own tools and procedures. The sales agent never touches source code, and context never bleeds across domains.

  • 04 // Real scope

    Work from the backlog

    Issues the team actually opened: async race conditions, component migrations, end-to-end test suites, lead routing into the CRM.

How it's built
