O que precisou existir antes

Salvaguardas

Repositórios de produção precisam de mais que um bom modelo. É isso que torna a delegação real.

  • 01 // Revisão humana

    Nenhum push direto, nunca

    No máximo 2 PRs abertas por repositório, pra não afogar o time. O agente roda os testes locais, o CI precisa passar verde e um engenheiro revisa e faz o merge do código de produção. Repositórios de baixo risco, como o site institucional, fazem auto-merge com o CI verde.

  • 02 // Escopo real

    Problemas reais, zero perfumaria

    Nada de mudança cosmética ou refatoração de espaçamento. O agente pega issues reais do backlog: condições de corrida assíncronas, migração de componentes e suítes de testes ponta a ponta.

  • 03 // Isolamento

    Cada agente na sua área

    Cada perfil roda num sandbox isolado, com ferramentas e procedimentos próprios. O agente de vendas nunca encosta no código-fonte, e o contexto de uma área nunca vaza para outra.

  • 04 // Custo e segurança

    Scripts antes de LLM

    O que dá pra resolver com Bash, Python ou Git nunca chama um LLM. Isso evita alucinações, roda checagens de segurança em silêncio e mantém o gasto de tokens estritamente abaixo de $140 por mês por perfil.

Como é construído

Self-hosted

De ponta a ponta — o runtime do agente, o estado em SQLite e cada integração rodam em infraestrutura própria, desacoplados dos provedores de inferência. Trocar o modelo é mudar uma configuração; as salvaguardas e o processo de revisão continuam iguais.
