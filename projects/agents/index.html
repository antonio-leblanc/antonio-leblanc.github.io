Production AI Agents

I build the ecosystem, tools, integrations, and orchestration that give a foundation model the ability to take real action.

  • 8 AI agents in production: one control plane that writes engineering PRs and audits the infrastructure, and seven working inside sales, CS, support, marketing, projects, fire alerts, and leadership.
  • A person reviews and merges every PR. The agent's autonomy is authorship — it opens the pull request, someone on the team merges it.
  • Self-hosted on our own servers, on Hermes — the open-source agent runtime by Nous Research.

The agents

The control plane carries both hard numbers below. The other seven run one area each, next to the person who owns it.

Writing code

291 PRs written and 171 issues closed by the agent, in the first 3 months. A person reviewed and merged every one.

Running infrastructure

Cut 15% of AWS infrastructure costs. A watchdog checks every agent profile every 15 minutes.

Beside the teams

Seven area agents — sales, CS, support, marketing, projects, fire alerts, leadership. Each one delivers its morning briefing to the person who owns that area.

Guardrails that make delegation real

An agent opening pull requests against production repositories needs more than a good model. This is what had to exist first.

Human Review

The agent opens the PR; a person reviews and merges it. Scheduled jobs open their issues raw, with no project label attached, so a human has to triage them.

Strategic Governance

Weekly OKR review cross-checks the board against the quarter's key results, flagging epics with no linked KR.

Delivery Pipeline

Backlog runs on GitHub Projects — Sprint and Epic boards — plan, issue, PR, same system as the code.

Self-Healing

A cognitive audit reviews the agents' own memory and skill usage, opening issues against itself to refactor.

State as Code

Runtime config and memory sync to GitHub via automated PR twice a week.

Security Watchdogs

A backend audit scans for vulnerabilities every weekday morning; a separate web audit runs weekly. Only a nonzero finding pages the team on Telegram.

Recursive Audit

Every Monday, a dedicated job reviews every other scheduled job across all agent profiles — stale schedules, silent failures — before they compound.
