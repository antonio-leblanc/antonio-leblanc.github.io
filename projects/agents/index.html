Guardrails that make delegation real

An agent opening pull requests against production repositories needs more than a good model. This is what had to exist first.

Human Review & WIP Throttling

The agent never floods the queue: capped at a strict 2-PR limit per repo. Issues are broken down deterministically via github-issue-worker. Local tests must run and CI must pass green before human notification. Zero direct pushes to main or staging.

Real Engineering Scope

No cosmetic code churn. Tested production work: async race conditions in map rendering, migrating Angular NgModules to Standalone Components with ugm-angular-frontend-standards, Playwright E2E suites with pantera-web-test-gari, and Nginx edge compression.

Subagent Isolation & Skills

Complex tasks fan out via subagent-driven-development with isolated delegate_task execution. Procedural skills are loaded dynamically on demand instead of bloated static prompts, preventing context bleed and limiting blast radius.

Unit Economics & Security

Daily SAST vulnerability scans notify directly on Telegram only on actionable findings. Cloud waste is pruned via aws-finops-audit. Granular token telemetry caps operational spend under $120/month even for our heaviest full-time engineering agent.

How it's built

Self-hosted end to end — the agent runtime, SQLite state, and every integration run on our own infrastructure, decoupled from inference providers.
